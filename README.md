# Flutter апликација за каталог на игри
## Опис на проектот

Game Catalog е мобилна апликација развиена во Flutter, која им овозможува на корисниците да прегледуваат, филтрираат и управуваат со видео игри. Апликацијата комбинира податоци повлечени од надворешен API со локално креирани игри кои ги управува корисникот.

Корисникот мора да се логира во апликацијата пред да пристапи до главните функционалности.

## Извори на игри

Апликацијата нуди два основни начина за преглед на игри:

### API игри

Игри кои се преземаат преку повик кон надворешен API.

**Карактеристики:**
* Прикажување на листа на игри од API
* Филтрирање на игри по:
  * Име
  * Рејтинг
* Сортирање на игри:
  * Азбучно (A до Z)
  * Азбучно (Z до A)
* Додавање игри во листата на омилени (Favorites)

### Локални игри креирани од корисникот

Игри кои корисникот ги креира и управува со нив директно во апликацијата.

**Поддржани CRUD операции:**
* Create – Креирање нова игра
* Read – Преглед на детали за игра
* Update – Измена на постоечка игра
* Delete – Бришење на игра

**Дополнителни функции:**
* Исти опции за филтрирање како кај API игрите:
  * Филтрирање по име
  * Филтрирање по рејтинг
* Исти опции за сортирање:
  * А до Z
  * Z до А
* Додавање на локални игри во листата на омилени (Favorites)

### Листа на омилени (Favorites)

Корисникот може да додаде било која игра (API или локална) во листата на омилени.

Во листата на омилени, корисникот може:
* Да ги прегледа сите омилени игри
* Да ги филтрира по име
* Да ги филтрира по рејтинг
* Да сортира азбучно (A до Z, Z до A)
* Да отстрани игра од листата

### Функционален тек на апликацијата

1. Корисникот се логира или регистрира.
2. Избира дали ќе се прегледува API игри или локално креирани игри.
3. Може да:
   * Филтрира
   * Сортира
   * Додава во омилени
4. Управување со локални игри (CRUD операции).
5. Прегледува и филтрира омилени игри.
